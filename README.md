# Vibetyper

Site de apresentação de um teclado mecânico fictício para Mac, com modelo 3D interativo, animação de abertura e seções controladas pela rolagem. A interface está em português do Brasil.

## Executar

```bash
npm install
npm run dev
```

Abra o endereço local mostrado pelo Vite. Para gerar a versão de produção:

```bash
npm run build
```

As texturas do teclado e as fontes são carregadas de serviços externos. Os links de pré-venda e comparação são provisórios.

O projeto foi construído a partir do prompt e dos ativos do template Vibetyper da Uberdesigner; o uso e o compartilhamento seguem a licença do fornecedor.
